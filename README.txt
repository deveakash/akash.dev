IMPORTANT BEFORE DEPLOYING:
1. Add your own portrait photo as: assets/akash-photo.jpg
   Use a clear, professional headshot, preferably portrait orientation. If the photo is missing, the hero displays an AS placeholder.
2. In script.js, replace YOUR_EMAIL@example.com with your real email address. The form opens an email draft; it does not submit to a server.
3. Check the project demo URLs in index.html and update them if needed.
4. This design uses Google Fonts and Font Awesome CDN, so internet access is needed for those resources.
5. Demo projects are labelled as concepts/demos, not paid client projects.
